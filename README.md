## 三、主看板怎么读

1. **先看顶部「大盘趋势」** → 定总仓位（强势100% / 中性50% / 弱势20%）
2. **看表格综合得分前N名** → 结合风控通过标记
3. **看「5日收益 / 10日收益」** → 判断短线动能强不强、是不是刚启动
4. **看「信号天数」** → 越长说明趋势越稳，刚触发（1~2天）是新信号
5. **看「最优持股」** → 历史回测出来最合适的持有周期
6. **按「操作」标签执行** → 🟢加仓 / 🔵网格 / 🟡持有 / 🔴止损

### 三因子模型

- **M 动量（40%）**：近10日涨幅×60% + 近20日涨幅×40%
- **V 相对低位（30%）**：60日价格分位，越低分越高
- **F 资金流（30%）**：5日均量 / 20日均量 × 50

### 三重风控

① 价格站上20日均线　② 20日均线向上　③ 3日跌幅不超过 -5%

## 五、参数速查（改 `etf_rotation.py` 顶部）

| 参数 | 默认 | 含义 |
|------|------|------|
| `MOMENTUM_SHORT` | 10 | 动量短周期（天） |
| `MOMENTUM_LONG` | 20 | 动量长周期（天） |
| `V_PERIOD` | 60 | 价格分位窗口 |
| `MA_PERIOD` | 20 | 均线周期 |
| `STOP_LOSS` | -5.0 | 止损线（%） |
| `MAX_HOLD` | 2 | 中性时持仓数量 |
| `HOLD_SIGNAL` | 2 | 信号定义取前N名 |

**改定时**：编辑 `.github/workflows/daily-update.yml` 里的 cron（UTC时间，比北京时间早8小时）。
