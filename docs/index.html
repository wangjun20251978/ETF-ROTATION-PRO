📌 10日收益：近10个交易日累计涨幅，也用于M动量因子计算(占60%)。
📌 信号天数：综合进入前N(中性前2)且三重风控连续通过的天数。天数越长=趋势越稳；刚触发(1~2天)=新信号，可建仓观察。
